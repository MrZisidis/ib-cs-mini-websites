Understanding IB Computer Science (2027 Specification)

The 2027 IB Computer Science curriculum emphasizes computational thinking, algorithmic problem-solving, software engineering principles, and synoptic case study evaluation across Standard Level (SL) and Higher Level (HL).

📝 SL 35% | HL 35%

Paper 1: Theoretical Fundamentals & Systems

Written theoretical examination evaluating core computer science principles, system architecture, data representation, networks, and system security.

  • Computer organization & von Neumann architecture
  • Network topology, TCP/IP & cybersecurity
  • Data structures, arrays & ADTs
  • Environmental, ethical & social impacts
💻 SL 35% | HL 45%

Paper 2: Applied Thinking & Case Study

Written exam focused on algorithmic problem-solving, code tracing, programming concepts, and deep analysis of the annual Case Study.

  • Algorithm design & pseudocode trace tables
  • Object-Oriented Programming (OOP) paradigms
  • Annual Case Study (Generative AI for Image Creation)
  • Software evaluation & algorithmic complexity
🛠️ SL 30% | HL 20%

Internal Assessment: Computational Solution

A 30-hour practical project where students analyze, design, develop, test, and evaluate a fully functional software application for a client.

  • Criterion A: Problem definition & client needs
  • Criterion B: Detailed system design & test plans
  • Criterion C: Computational development & implementation
  • Criterion D & E: Testing, video demo & evaluation
